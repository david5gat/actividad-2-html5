# Actividad 2 - Implementación de una página HTML5 básica

## GatoSoftware

### 1. Propósito de la página

La página web desarrollada tiene como propósito presentar el proyecto GatoSoftware y mostrar información básica sobre los servicios relacionados con el desarrollo de software.

El público objetivo está compuesto principalmente por pequeñas empresas, emprendedores y personas interesadas en conocer soluciones tecnológicas para mejorar sus procesos.

### 2. Estructura semántica

Para desarrollar la página se utilizaron diferentes etiquetas semánticas proporcionadas por HTML5:

* `<header>`: contiene el encabezado y la identificación de la página.
* `<nav>`: contiene los enlaces principales de navegación.
* `<main>`: contiene el contenido principal.
* `<section>`: permite organizar el contenido en diferentes secciones.
* `<article>`: contiene información independiente sobre GatoSoftware.
* `<aside>`: presenta información complementaria sobre las tecnologías utilizadas.
* `<footer>`: contiene información adicional y derechos de autor.

El contenido se organizó utilizando una jerarquía lógica de títulos mediante las etiquetas `<h1>` y `<h2>`.

### 3. Accesibilidad

Se implementaron diferentes buenas prácticas de accesibilidad:

* Se estableció el idioma de la página mediante `lang="es"`.
* La imagen incluida tiene un atributo `alt` descriptivo.
* Los campos del formulario tienen etiquetas `<label>` asociadas correctamente mediante los atributos `for` e `id`.
* La navegación principal puede utilizarse mediante el teclado.
* Se utilizó `aria-label` para identificar claramente la navegación y el botón del formulario.
* Los elementos HTML fueron organizados de manera lógica para facilitar la interpretación mediante lectores de pantalla.
* Se utilizó un diseño estructurado que permite recorrer el contenido mediante la tecla Tab.

### 4. Buenas prácticas HTML5

Se utilizó:

* Declaración `<!DOCTYPE html>`.
* Codificación UTF-8.
* Etiqueta `meta viewport` para mejorar la visualización en dispositivos móviles.
* Meta descripción para proporcionar información sobre la página.
* Etiquetas semánticas HTML5.
* Atributos descriptivos para elementos que requieren accesibilidad.
* Comentarios dentro del código para explicar las decisiones tomadas.

### 5. Validación

El código HTML debe ser validado utilizando el servicio oficial W3C Markup Validation Service.

La validación permite comprobar que la estructura HTML cumple con las especificaciones y ayuda a identificar errores en el código.

Para visualizar la página localmente, se puede abrir el archivo `index.html` utilizando cualquier navegador web moderno como Google Chrome, Microsoft Edge o Mozilla Firefox.
